# Tile art credits

All tiles in `tilesets/` come from the Liberated Pixel Cup project on
OpenGameArt.org. **You must credit the authors below in any game or map that
uses these tiles.** Each pack's original credits file is kept next to its
images as `CREDITS.txt`. The editor also adds a `CREDITS.txt` listing the
packs a map uses to every export.

## LPC Base Assets — `tilesets/lpc-base/`

- Source: https://opengameart.org/content/liberated-pixel-cup-lpc-base-assets-sprites-map-tiles
- License: CC-BY-SA 3.0 or GPL 3.0
- Authors:
  - Lanea Zimmerman (Sharm): terrain, house, interior, water, trees and
    most other base tiles. These are **also available under OGA-BY 3.0**.
  - Daniel Armstrong (HughSpectrum): `castlewalls.png`, `castlefloors.png`,

## Releasing on DRM-protected stores

CC-BY-SA does not allow DRM, which can be a problem on stores such as Steam
or the App Store. Of the tiles here, only Lanea Zimmerman's base tiles are
also offered under OGA-BY 3.0, which does allow DRM.
